# Contributing

Contributions are welcome, from questions and bug reports to code.

## Questions and issues

Questions about the data are best raised on the website, where the team can triage them. Issues here work best for a specific problem in the pipeline code or its docs.

| If you want to…                                                                        | Raise it at                                                                                      |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| report a figure that looks wrong, or ask how a source is modelled                      | the feedback form on the [DFO website](https://developmentfinance.org)                           |
| request a new source or dataset                                                        | "Submit Request" on the [roadmap](https://developmentfinance.org/data/roadmap)                   |
| report a bug or failing step in a pipeline, a setup problem, or an error in these docs | an issue in this repository                                                                      |
| report a problem with a concept, property or code list in the ontology                 | an issue in the [ontology repository](https://github.com/DevelopmentFinanceObservatory/ontology) |
| improve an agent skill                                                                 | an issue in the [skills repository](https://github.com/DevelopmentFinanceObservatory/skills)     |

## Contributing code

Open an issue before submitting a pull request, so the change can be discussed before you make it.

Set up the project and run the tests and checks as described in the [README](README.md). Each pull request addresses a single issue and follows the [pull request template](.github/pull_request_template.md).

Commit messages and pull request titles follow [Conventional Commits](https://www.conventionalcommits.org/), scoped to the pipeline where one applies.
